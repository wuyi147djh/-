# PROJECT FRONTIER — Android FPS prototype
Godot 4.3 ARM64 Android prototype. Includes procedural forest/river/road/outpost environment, first-person movement and look, firing/reload, simple pursuing enemies, health, HUD and touch controls. This is an early playable vertical slice, not a finished AAA game. Photorealistic asset packs, motion-captured animation, cinematic intro, authored terrain and advanced squad AI remain future work.
Controls: touch left side to move, drag right side to look; FIRE/AIM/JUMP/CROUCH/RELOAD buttons.
